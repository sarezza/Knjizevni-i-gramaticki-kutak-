# Књижевни и граматички кутак 📚

Интерактивни сајт за **српски језик и књижевност, IV разред гимназије**.

## Садржај

- **15 књижевних дела / тематских целина** са обрађеним темама, мотивима, поетиком и школским белешкама.
- **30 ликова** из шест дела, са кратким описима.
- **54 појма** из књижевности, поетике, стилистике и наратологије.
- **11 граматичких лекција** укључујући падеже, интерпункцију, функционалне стилове, независне и посебне реченичне конструкције.
- **179 интерактивних питања**: један одговор, више тачних одговора, повезивање, кратки цитати и одломци.
- **Претраживање** српском ћирилицом и латиницом, филтери по области, објашњења одговора, праћење напретка и обележавање дела.
- **Тамна тема**, прилагођено телефонима.

## Фајлови

| Фајл | Садржај |
| --- | --- |
| `index.html` | Главне секције и мени |
| `style.css` | Дизајн, мобилни приказ |
| `data.js` | Почетни подаци, оригинална питања |
| `gradivo-4.js` | Детаљније белешке, додатна дела, појмови, граматика, ликови |
| `pitanja-4.js` | 138 нових питања |
| `app.js` | Претрага, тестирање, бодовање, напредак |

Странице раде без инсталације и сервера. Подаци о резултатима чувају се локално у прегледачу, а не на GitHub-у.

## Објављивање на GitHub Pages

У **Settings → Pages** изабери **Deploy from a branch**, грану **main** и директоријум **/(root)**, па **Save**. Када се сајт објави, GitHub ће показати јавну адресу.

## Уредничке напомене

- Тумачења симбола су **могућа читања**, а не једина исправна решења.
- Код `Писма` и осталих песама прецизне податке о стиху, распореду строфа и одломцима треба проверити према тексту из читанке.
- Подела „специјалних“ реченица зависи од терминологије уџбеника; потребно је ускладити је са достављеном лекцијом.
- Секција **Одломци** садржи само неколико кратких проверених цитата и формулација. За додатне задатке препознавања стихова користићемо делове текста које пошаљеш.
- Сачуване ознаке и историја тестова остају у истом прегледачу при допунама сајта.
